==================================

The Woof app is a list of dog photos with information about them including their name, age, and favorite activity. This app also uses Material Design to create a beautiful app experience for the user.

Introduction
------------

This is the starter code for the Woof app project. This project is an opportunity for you to learn Material3 and reinforce the concepts you've learned so far in Android Basics with Compose.

Pre-requisites
--------------

- Rows/Columns
- Modifiers
- Scaffold
- Adding images
- Button click handlers
- Functions
- Classes
- Lists
- App architecture

Getting Started
---------------

1. Download the project
2. Open the project in Android Studio
3. Run the Project

Aplicación de los elementos de diseño a una lista de gastos

1. Tarjetas: utilizaría tarjetas con esquinas redondeadas para organizar cada gasto y separar visualmente los registros.
2. Jerarquía de texto: mostraría el nombre del gasto en negrita y debajo colocaría la fecha y otros detalles con un tamaño de letra menor.
3. Color y contraste: utilizaría colores con buen contraste para distinguir los gastos, los ingresos y los totales, facilitando la lectura de la información.
